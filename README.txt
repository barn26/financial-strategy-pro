# Financial Strategy 2026 PRO — PWA

Файли (усі мають лежати в одній папці):
index.html, manifest.json, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

## Як розмістити (потрібен https)
1. Netlify Drop: відкрийте app.netlify.com/drop і перетягніть цю папку — отримаєте https-посилання.
   Альтернативи: GitHub Pages, Cloudflare Pages.
2. Відкрийте посилання на телефоні/ПК.

## Як встановити
- Android / Chrome / Edge: кнопка «📲 Встановити» в програмі або меню браузера → «Встановити застосунок».
- iPhone / iPad (Safari): «Поділитися» → «На початковий екран».

## Офлайн
Після першого відкриття з інтернетом програма працює без мережі. Дані зберігаються на пристрої.
Розпізнавання чеків офлайн працює, якщо воно вже хоч раз виконувалось з інтернетом.

## Оновлення
Достатньо замінити на GitHub один файл index.html (Add file -> Upload files -> Commit changes).
Програма сама побачить нову версію і запропонує оновитись (або Налаштування -> Оновлення програми -> Перевірити).
Файл sw.js змінювати не потрібно.
